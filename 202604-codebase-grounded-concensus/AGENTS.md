このプロジェクトは、「Codebase-Grounded Consensus：AI エージェントによるソフトウェア変更を検証可能にする合意層の再設計」という題名のレポートを書くためのものです。

## Inputs

* `src/{n}.md`: レポートに含めるべき内容のサマリ。第{n}章
* `src/ABSTRACT.md`: レポートの要旨案
* `src/REFERENCES.md`: このレポートを書くにあたっての参考文献
* `REVIEW.md`: レビュー結果

## Artifacts

* `ABSTRACT.md`: レポートの要旨。
* `REFERENCES.md`: レポートの参考文献一覧
* `TOC.md`: 目次
* `sections/{n}.md`: 第{n}章

## Writing Rules

* 日本語を使って記述すること。
* 学術論文としてふさわしい文体を用いること。
* 略語・接頭語を使用する前に、必ず定義すること。前章で定義済みの場合、再定義する必要はありません。
  * JSON や YAML など、ソフトウェア開発の慣行上極めて一般的な用語についてはこの限りではありません。
* 参考文献の内容をもとにした記述においては、必ず出典を明らかにすること。
* 各章はレベル2の見出し（`##`）で開始すること
