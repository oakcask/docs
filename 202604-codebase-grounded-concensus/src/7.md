# 第7章　実装パターン：PR テンプレート、ADR、arch test、CI の連携

## 概要

本章では、Codebase-Grounded Consensus を実務に導入するための具体的な実装パターンを示す。中心となるのは、PR テンプレート、ADR、dependency decision record、arch test、CI チェック、コード検索、静的解析を組み合わせたワークフローである。

PR では、何を変更したかだけではなく、どの不変条件を変更したのか、どの設計判断を行ったのか、どの証拠によって安全性を確認したのかを明示する。ADR は大きな設計判断や依存ライブラリの選定理由を記録する。arch test や linter は、境界違反や依存関係の逸脱を自動的に検出する。

また、AI agent は PR 作成時に structural claims を自動生成し、CI 結果やテスト結果と対応づける。人間は、AI が提示した主張と証拠の整合性をレビューする。

## 本章で扱う論点

- PR テンプレートに含めるべき項目
- ADR と dependency decision record の使い分け
- arch test によるアーキテクチャ制約の検証
- CI による evidence collection
- AI agent による claims / evidence 対応表の生成
- 実務導入時の最小構成
