# 第2章　先行提案としてのコンセンサス層 C

## 概要

本章では、対象論文が提案するコンセンサス層 C の概要を整理する。論文は、コードが一次元のテキストとして表現されることで、設計意図や構造的判断が十分に記録されないという問題を指摘している。その解決策として、コードとは別に、AI agent と人間が共有できる構造化された合意層を導入しようとしている。

C は、単なるコメントやドキュメントではなく、構造的な主張、不変条件、依存関係、設計判断、ライブラリ選定理由などを明示的に保持する層として構想されている。これにより、AI agent は過去の判断や現在の制約を参照しながらコード変更を行い、人間は差分そのものではなく、構造的な意図と証拠をレビューできるようになる。

本章では、C の問題意識を肯定的に整理したうえで、それが解決しようとしている本質的課題を抽出する。

## 本章で扱う論点

- 論文が指摘する dimension collapse の問題
- コードだけでは明示されにくい構造的意図
- C が記録しようとする情報の種類
- AI agent と人間の共通理解としての C
- C の意義と期待される効果
