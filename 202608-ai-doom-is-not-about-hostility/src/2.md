## 第2章　病原体は人類を憎まない――生物安全という先行モデル

### この章の役割

黒死病、1918年インフルエンザ、COVID-19のような感染症では、病原体の意図を問わずに危機を分析し、封じ込めてきたことを示す。AI安全にも、意図ではなく経路を管理する考え方を導入する。

### 含める内容

- 世界保健機関（World Health Organization; WHO）の『Laboratory Biosafety Manual』第4版は、危険源への曝露または放出について、発生可能性と結果を評価するリスクベース・アプローチを採る（WHO, 2020）。
- 生物安全の基本的な因果鎖を「危険源→曝露・放出→伝播→増幅→被害→封じ込め」と整理する。病原体が人類を敵視する確率は変数に入らない。
- 感染症では、感染源、排出経路、伝播経路、侵入経路、感受性宿主などの連鎖を特定し、いずれかを切ることで被害を抑える。同様にAIでも、危険な能力から破局までの鎖を途中で切ればよい。
- WHOの『Laboratory Biosecurity Guidance』は、事故だけでなく、盗難、悪用、不正アクセスなど意図的脅威も生物学的リスク管理の対象とする（WHO, 2024）。これは、AI自身の危険な振る舞いと、人間によるAIの悪用を同じ管理体系で扱えることを示唆する。

### AIへの写像

| 生物安全 | AI安全 |
|---|---|
| 病原体・危険因子 | 危険を生じさせ得るAI能力 |
| 保有場所・リザーバー | モデル、重み、実行環境 |
| 曝露・放出 | 出力、API、ツール呼び出し、ネットワーク接続 |
| 伝播経路 | 自動実行、人間による転送、他システム連携 |
| 増殖・拡散 | 複製、並列化、自動化、連鎖的操作 |
| 感受性宿主 | 脆弱な人間、組織、情報システム |
| 封じ込め | サンドボックス、権限制限、ネットワーク隔離 |
| サーベイランス | 評価、ログ、異常検知、監査 |

### 導く結論

病原体が無害であることを生物安全の必要条件にしないのと同様に、AIが善良または完全にアラインしていることを安全の唯一の必要条件にしない。危険源の発生を減らす対策と、危険源が生じた後の封じ込めを併用する。

### 注意点

- AIは病原体と異なり、言語、計画、制度利用、人間との協働が可能である。アナロジーは同一性の主張ではなく、意図から経路管理へ視点を移すために使う。
- 「感染」の比喩を過度に展開せず、具体的な制御手段へ接続する。
