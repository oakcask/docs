## 15. Threats to Validity: 妥当性への脅威

### 含める内容

- 研究レポートとして、限界を明示する。

### 内的妥当性

- モデル固有の得意不得意に依存する可能性。
- プロンプト設計に結果が左右される可能性。
- タスク選定が言語ごとの有利不利を作る可能性。

### 外的妥当性

- 小規模タスクの結果が大規模開発に一般化できるとは限らない。
- OSS 的タスクと業務システムでは要求が異なる。
- 特定のエージェント実装に依存する可能性。

### 構成概念妥当性

- 「高速生成」を時間だけで測ると、品質・保守性・レビュー負荷を見落とす。
- 「成功」をテスト通過だけで測ると、設計品質やセキュリティを見落とす。

### 統計的妥当性

- 試行回数が少ないと分散を評価できない。
- モデル更新により再現性が失われる。
- API latency やキャッシュの影響を除去しにくい。
