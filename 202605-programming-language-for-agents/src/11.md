## 11. Agent Interaction Model: AIエージェントとの相互作用設計

### 含める内容

- AIエージェントがどのようにこの言語・ツールチェーンを使うかを明示する。
- 通常のコンパイラではなく、**agent-facing compiler** として設計する。

### エージェントの基本ループ

```text
1. 仕様を読む
2. 関連モジュールを graph で絞る
3. typed hole を含む実装を生成する
4. veln check --json を実行する
5. 診断を読む
6. failing tests と hole 情報から修正する
7. affected tests のみ再実行する
8. contract / doctest / docs を更新する
```

### 設計すべきインターフェース

- Language Server Protocol 拡張。
- JSON diagnostics。
- dependency graph API。
- affected test selection。
- code action / safe repair API。
- typed hole completion API。
- contract explanation API。
- doc drift detection API。
