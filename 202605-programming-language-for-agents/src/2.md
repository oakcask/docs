## 2. Related Work: 先行研究と理論的背景

### 2.1 コードの自然性と LLM 生成

### 含める内容

- ソースコードは自然言語と同様に反復性・予測可能性を持つという “naturalness of software” の議論を整理する。
- LLM がコードを生成しやすい言語とは、単に人気がある言語ではなく、頻出パターンが安定し、慣用句が明確で、局所的な予測可能性が高い言語であると位置づける。
- Big Code / code naturalness 研究は、コード中の統計的規則性を補完・バグ検出・モデル化に利用できることを整理している。

### 2.2 プログラミング言語の簡潔性

### 含める内容

- Rosetta Code を用いた比較研究では、スクリプト言語や関数型言語が手続き型・OOP言語より簡潔になりやすいことが報告されている。
- ただし、簡潔性は「短ければよい」ではない。
  - Perl 的な圧縮性ではなく、Ruby / Python 的な「意味密度が高く、読める」簡潔性を区別する。
- 本研究では、以下を区別する。
  - **token density:** 少ない token でどれだけ処理を表現できるか。
  - **semantic density:** 少ない構文でどれだけ仕様意図を表現できるか。
  - **repair density:** 修正時にどれだけ小さい範囲を変更すればよいか。

### 2.3 認知的次元と記法設計

### 含める内容

- Green / Petre の Cognitive Dimensions of Notations を、AI向け言語設計にも拡張して使う。
- 観点例：
  - viscosity: 変更のしにくさ
  - hidden dependencies: 隠れた依存
  - visibility: 必要情報の見えやすさ
  - consistency: 記法の一貫性
  - error-proneness: エラーを誘発しやすい設計
- Cognitive Dimensions は、プログラミング言語や記法の usability を分析する軽量な枠組みとして使われてきた。
- 本研究では、これを人間だけでなく AIエージェントの「読解・修正・探索負荷」に適用する。

### 2.4 静的型付け・段階的型付け・保守性

### 含める内容

- 静的型付けは保守性に有利な場合があるが、万能ではない。
- Hanenberg らの実験では、静的型は未文書コードの理解や型エラー修正には有益だが、意味的エラー修正には必ずしも有効ではないと報告されている。
- 本研究では、全域的な強制型付けではなく、以下の方針を採る。
  - 初期生成は軽い。
  - 公開API・永続化・外部I/O・安全性境界では型を強くする。
  - 内部処理は型推論・段階的型付け・契約で補助する。

### 2.5 typed holes / partial program / sketching

### 含める内容

- AIエージェントは、完全な初回実装よりも、穴を残して段階的に補完・検証する方式と相性がよい。
- Hazel / Hazelnut 系研究は、穴を持つ不完全プログラムにも型・実行意味論を与える方向を示している。
- Program sketching は、人間が高水準の実装方針を与え、低レベル詳細を合成器が埋めるという設計を示す。
- 本研究では、typed holes を AIエージェントの「作業単位」として扱う。

### 2.6 モジュール化と情報隠蔽

### 含める内容

- Parnas のモジュール分割論を導入する。
- モジュールは単なる手続き分割ではなく、「変更されうる設計判断」を隠蔽する単位である。Parnas は、モジュール化を柔軟性・理解容易性・開発期間短縮のための機構として論じた。
- AI向け言語では、モジュール境界をエージェントの探索範囲削減に使う。
  - 公開API
  - 不変条件
  - 副作用
  - 依存先
  - テスト責務
  - 変更理由

### 2.7 contract / unittest / doctest / 統合ツールチェーン

### 含める内容

- D 言語は unittest を言語仕様として持ち、モジュール単位の組み込みテストを提供している。
- Elixir は doctest と Mix / ExUnit により、ドキュメント・テスト・プロジェクト管理を近接させている。
- 本研究では、これらを AIエージェント向けに再解釈する。
  - コードと仕様を近接させる。
  - 実行可能な例を標準化する。
  - テスト失敗を構造化診断として返す。
