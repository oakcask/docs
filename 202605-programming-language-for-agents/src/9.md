## 9. Toolchain Design: エージェント向け標準ツールチェーン

### 含める内容

- 言語仕様だけでなく、ツールチェーンを研究対象に含める。
- AIエージェントにとって、formatter / linter / test runner / type checker / package manager / documentation generator が分裂していることは大きな摩擦になる。

### 標準コマンド案

```text
veln init
veln run
veln test
veln check
veln fmt
veln doc
veln graph
veln explain
veln repair
```

### 各コマンドの責務

| コマンド | 内容 |
|---|---|
| `veln run` | 即実行 |
| `veln test` | unit / doctest / property test を実行 |
| `veln check` | 型・契約・effect・lint を統合検査 |
| `veln fmt` | 標準スタイルへ正規化 |
| `veln doc` | API docs と examples を生成 |
| `veln graph` | dependency graph / call graph / effect graph を出力 |
| `veln explain` | エラー・型・依存を説明 |
| `veln repair` | safe autofix 候補を生成 |

### 構造化出力

- すべてのコマンドは人間向け表示と JSON 出力を持つ。
- AIエージェントは JSON を読み、人間は通常の表示を読む。
- 例：

```json
{
  "status": "failed",
  "failures": [
    {
      "kind": "contract_violation",
      "file": "src/users.veln",
      "line": 42,
      "symbol": "Users.create",
      "expected": "email is valid",
      "actual": "empty string",
      "suggested_tests": ["reject empty email"]
    }
  ]
}
```
