## 要旨案

### 含める内容

- 本レポートの問題意識を簡潔に述べる。
  - 近年の AI コーディングエージェントは、言語ごとに生成速度・修正速度・コストが異なる。
  - Ruby / Python / JavaScript のような動的・簡潔な言語が小規模タスクで高速に見える一方、大規模開発では型・契約・検証支援が必要になる。
- 本研究の提案を一文で示す。
  - **AIエージェントにとっての作業面積を最小化する言語設計**。
  - 短い表層構文、標準化されたツールチェーン、局所的静的検査、構造化診断、typed holes、contract、doctest を統合する。
- 主張を要約する。
  - 「AI向け言語」は単に動的型付けであればよいのではない。
  - 生成・読解・実行・失敗・修正のループ全体を短縮する設計が必要である。
