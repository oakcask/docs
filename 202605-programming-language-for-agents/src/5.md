## 5. Core Language Design: 中核言語設計

### 含める内容

- 言語の表層構文と中核意味論を分けて説明する。
- 表層は Ruby / Python 的に短く、意味論は小さく・直交的にする。
- 「AIが生成しやすい」ことと「人間が読める」ことを同時に満たすため、構文上の選択肢を制限する。

### 提案する特徴

- Ruby 風のブロック構文。
- Elixir 風の pipeline。
- ML 風の pattern matching。
- Python 風の標準スタイル重視。
- D 風の contract / unittest。
- TypeScript / Gradual Typing 風の optional type annotation。
- Haskell / Hazel 風の typed holes。

### 例示すべきコード

- ファイル処理。
- JSON / TOML 設定読み込み。
- CLI コマンド。
- HTTP API handler。
- 小さなデータ変換 pipeline。
- contract 付き関数。
- typed hole を含む未完成関数。
