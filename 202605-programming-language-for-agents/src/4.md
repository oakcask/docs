## 4. Non-Goals: 本研究で扱わないこと

### 含める内容

- 過剰な期待を避けるため、対象外を明示する。
- Brooks の “No Silver Bullet” を踏まえ、本質的複雑性を消すのではなく、偶有的複雑性を減らす研究として位置づける。Brooks はソフトウェア開発において本質的困難と偶有的困難を区別した。

### Non-Goals

- 実行時性能で C / Rust に勝つこと。
- すべてのバグを型システムで防ぐこと。
- 人間の設計判断を不要にすること。
- 自然言語だけで完全なソフトウェアを生成すること。
- IDEやエージェントに依存して、ソースコードそのものの可読性を犠牲にすること。
- 既存言語を全面的に置き換えること。
