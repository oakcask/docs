## 第7章 ソフトウェアエンジニアリングはマネジメントでもある

この章では、「ソフトウェアエンジニアリングは、ソフトウェアをマネジメントすることである」という指摘を検討する。マネジメントもまた、方針を立て、状況を観測し、資源を配分し、制約を調整し、組織をあるべき姿へ導く営みである。この意味で、ソフトウェアエンジニアリングとマネジメントには同型性がある。

文献支柱として、Stafford Beer の管理サイバネティクスと Viable System Model を使う。Viable System Model は、組織を環境変化に適応し続ける自己制御システムとして捉える枠組みである。初出時には、Viable System Model を「存続可能システムモデル」などと訳すか、英語名を併記して脚注で説明する。

この章の論点は次の通りである。

- マネジメントは、目標と現実の差分を扱い、資源と行動を調整する活動である。
- ソフトウェアプロダクト、開発組織、運用体制は、いずれも目的を持つ社会技術システムである。
- したがって、reconciliation loop はマネジメントのサイバネティックな記述とも接続できる。

同時に、ソフトウェアエンジニアリングの固有性も述べる。ソフトウェアでは、方針をコード、テスト、CI/CD、Infrastructure as Code、Policy as Code などの実行可能な人工物に変換できる。この点で、通常の組織マネジメントよりも観測、検証、自動化、再現性を強く持たせられる。
